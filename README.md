## ✨ Funcionalidades
- Jogabilidade estilo Flappy Bird: toque ou clique para o pássaro voar e desvie dos canos
- Sprite de pássaro personalizado
- O cenário muda de tema a cada 50 pontos
- Login com conta Google
- Ranking online com apelido escolhido pelo jogador

## 🎯 Como jogar
1. Faça login com sua conta Google
2. Escolha seu apelido para o ranking
3. Clique, toque ou use [tecla] para fazer o pássaro voar
4. Passe pelos canos sem encostar neles e faça o máximo de pontos
